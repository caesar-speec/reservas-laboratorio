# reservas-laboratorio

## Especificación breve

Sistema de reservas de equipos de laboratorio con Python y SQLite. Debe evitar reservas superpuestas para un mismo equipo, permitir horarios consecutivos, conservar las cancelaciones y persistir los datos.

## Solución

Estructura inicial preparada para una implementación posterior:

- `app.py`: punto de entrada previsto de la aplicación.
- `reservas.py`: lógica de reservas prevista.
- `database.py`: acceso a SQLite previsto.
- `inventario.json`: inventario inicial de cinco equipos.
- `data/`: datos persistentes generados durante la ejecución.
- `tests/`: pruebas futuras con unittest.
- `docs/`: documentación adicional.

Los archivos Python están vacíos. Todavía no se implementó la lógica del sistema.

## Preparación del agente

Leer `AGENTS.md` antes de realizar cambios y respetar sus instrucciones. Utilizar Python, SQLite y unittest. Mantener los datos persistentes y el historial de cancelaciones.
